# 任务：仅凭内部知识重建中国大陆地理轮廓

请仅凭你在训练过程中获得的内部地理知识，尽可能精确地重建中国大陆的二维地理轮廓，输出一组可用于绘制 SVG 地图的有序坐标点。

**禁止联网搜索、读取本地地图文件、调用地理信息数据库、使用预存的行政边界数据或其他外部地理数据源。**

## 一、地理范围

1. 目标为中国大陆连续陆地区域的完整外轮廓，包括陆地国界与海岸线。
2. 领土范围及争议地区的边界画法，统一采用**中华人民共和国官方立场**，以中国自然资源部发布的2023年版标准地图及相关国界线画法规范为准。
3. 包含所有与大陆连续的陆地区域，包括香港、澳门的大陆相连部分。
4. 排除海南岛、台湾岛以及所有其他与大陆不连续的岛屿。
5. 不需要绘制省级行政区划、河流、湖泊或其他内部地理要素。
6. 不绘制海上断续线。只输出一个连续大陆外轮廓。

## 二、坐标和轮廓规则

1. 使用 WGS84（EPSG:4326），坐标顺序为 [经度, 纬度]，单位为十进制度。
2. 顶点按逆时针排列。从最西端顶点开始，如有多个相同经度的顶点，则从纬度最低的顶点开始。
3. 最后一点必须与第一点完全相同。除闭合点外，不得重复顶点。轮廓不得自相交。
4. 最多输出 500 个不同顶点，末尾重复的闭合点不计入上限。
5. 在点数约束内，尽可能准确地表达整体轮廓和显著的边境转折、半岛、海湾与海岸走向。

## 三、输出格式

只输出一个合法 JSON 对象，不要加 Markdown 代码围栏、解释或其他文字。使用以下字段，示例坐标仅说明结构：

{
  "crs": "EPSG:4326",
  "region": "mainland_china",
  "orientation": "CCW",
  "points": [[73.5, 39.4], [74.1, 40.2], [74.0, 41.0], [73.5, 39.4]]
}
